install it

from this checkout

you'll need bun to build it. it installs to ~/.local/share/sprig and adds one line to your ~/.zshrc. sprig uninstall takes it back out.

$ scripts/install.sh
$ exec zsh   # or open a new tab

with homebrew

this repo is its own tap, so brew tap needs the url. sprig install adds the line to your ~/.zshrc, and brew upgrade sprig keeps it current.

$ brew tap john-rock/sprig \
    https://github.com/john-rock/sprig
$ brew install john-rock/sprig/sprig
$ sprig install

have your agent install it

using claude code, codex, cursor or another coding agent? copy the prompt and paste it in. it clones the repo, runs the installer and checks the setup with sprig doctor.

show the prompthide the prompt
Install sprig (https://github.com/john-rock/sprig), an IDE-style autocomplete dropdown for zsh, on this machine.

1. Check that zsh, git and Bun (https://bun.sh) are installed. If Bun is missing, ask me before installing it.
2. Clone the repo somewhere sensible, like ~/src/sprig, and run scripts/install.sh from inside the checkout.
3. If the script says ~/.local/bin is not on my PATH, add it in ~/.zshrc.
4. Run `sprig doctor` and fix anything it reports.
5. Don't change ~/.zshrc beyond that. When you're done, tell me to open a new terminal tab (or run `exec zsh`) to start using it.

something acting weird? run sprig doctor. daemon logs live in ~/.local/state/sprig/daemon.log. still stuck? open an issue on github.

0.1.0 nov 2, 2026
  • first release. a dropdown under your cursor with subcommands, options, branches, files and descriptions for 700+ clis, built on fig's open-source specs.
  • no terminal wrapper. zsh's own line editor draws the dropdown, so scrollback, resizing, tmux and ssh work like normal.
  • the daemon starts with your first shell, quits after an hour idle and never blocks typing.
  • suggestions you pick rank higher next time.
  • your own specs in ~/.config/sprig/specs/ override the built-in ones.
  • sprig install, sprig uninstall and sprig doctor to set up, remove and check it.

how it works

zsh

widgets send whatever's left of your cursor on every keystroke, then draw the dropdown under your prompt.

unix socketasync replies
sprig daemon

breaks up the line, walks the fig spec, runs stuff like git branch, and ranks what comes back.

settings

set these in your ~/.zshrc before the sprig block.

variabledefaultwhat it does
SPRIG_MAX_ROWS8how many rows show before it scrolls.
SPRIG_NO_DSRunsetdon't ask the terminal where the cursor is. the dropdown just starts at the left edge.
SPRIG_DEBUGunseta file path to log requests and replies to.
